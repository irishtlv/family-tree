# עץ המשפחה

אפליקציית עץ משפחה משותפת בעברית. כל קרוב/ה נכנס/ת עם המייל, רואה את כל העץ, ועורך/ת רק את הענף שלו/ה. המנהלת מאשרת שינויים.

עובד בנייד ובמחשב, ואפשר להתקין לטלפון כאפליקציה (״הוספה למסך הבית״).

## מה יש באפליקציה

- **משפחה**: אדם אחד במרכז, ההורים מעליו, בני הזוג, הילדים והאחים מתחתיו. נוח במיוחד בנייד.
- **עץ מלא**: כל העץ על משטח שאפשר לגרור ולהגדיל.
- **הרשאות לפי ענף**: ענף הוא אדם, כל הצאצאים שלו ובני הזוג שלהם.
  - מנהלת: עורכת הכל ומאשרת בקשות.
  - עורך/ת ענף: עורך/ת ישירות או באישור, לפי מה שהוגדר.
  - תורם/ת: כל שינוי נשלח לאישור.
  - צופה: צפייה בלבד.
- **עדכונים**: בקשות שממתינות לאישור, מה השתנה, והחזרת העץ למצב קודם (למנהלת).
- **ייצוא** ל-GEDCOM (לכל תוכנת עץ משפחה) ולגיבוי JSON.

ההרשאות נאכפות בשרת (פונקציות SQL ו-RLS ב-Supabase), לא רק במסך.

## הרצה מקומית (מצב הדגמה)

```bash
npm install
npm run dev
```

בלי הגדרות Supabase האפליקציה עולה במצב הדגמה: הנתונים נשמרים בדפדפן, ובמסך ״אני״ אפשר לעבור בין משתמשים לדוגמה כדי לראות מה כל אחד רשאי לעשות.

## העלאה לאוויר

### 1. Supabase (מסד הנתונים והכניסה)

1. נרשמים ב-[supabase.com](https://supabase.com) ויוצרים פרויקט חדש (התוכנית החינמית מספיקה).
2. ב-**SQL Editor** מריצים את כל התוכן של `supabase/schema.sql`.
3. אחר כך מריצים את `supabase/seed.sql` (טוען את העץ הקיים).
4. ב-**Authentication → Providers** מוודאים ש-Email מופעל.
5. ב-**Authentication → URL Configuration** מגדירים את כתובת האתר (אחרי שלב 2 למטה).
6. ב-**Project Settings → API** מעתיקים את `Project URL` ואת המפתח `anon public`.

### 2. Vercel (האתר)

1. נרשמים ב-[vercel.com](https://vercel.com) עם חשבון GitHub.
2. **Add New → Project**, בוחרים את המאגר `family-tree`.
3. ב-Environment Variables מוסיפים:
   - `VITE_SUPABASE_URL` = ה-Project URL
   - `VITE_SUPABASE_ANON_KEY` = המפתח anon public
4. Deploy.

### 3. כניסה ראשונה

מי שנכנס/ת ראשון/ה לאתר הופך/ת אוטומטית למנהלת. אחר כך, במסך **ניהול**, מזמינים קרובים לפי מייל, מקשרים כל אחד לאדם בעץ ובוחרים לו ענף.

## מבנה הקוד

| תיקייה | מה יש בה |
|---|---|
| `src/components` | המסכים: תצוגת משפחה, עץ מלא, פאנל פרטים, טפסים, עדכונים, ניהול |
| `src/lib/tree.ts` | לוגיקת העץ: קרבה, ענפים, הרשאות, החלת שינויים |
| `src/lib/layout.ts` | פריסת העץ המלא |
| `src/api` | שני צדי שרת עם אותו ממשק: הדגמה (דפדפן) ו-Supabase |
| `supabase/schema.sql` | טבלאות, הרשאות ופונקציות השרת |
| `src/data/seed.json` | נתוני העץ ההתחלתיים (`npm run seed-sql` מייצר מהם את `seed.sql`) |
